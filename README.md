# AutomatedPythonVideoMaker — Documentação Técnica

Repositório: https://github.com/AbimaelPereira/AutomatedPythonVideoMaker

Sumário rápido
- Propósito: Gerar vídeos automaticamente a partir de um arquivo JSON com cenas, fundos, elementos visuais, narração (TTS) e opção de upload ao YouTube.
- Entrada principal: arquivo JSON (estrutura detalhada em docs/configuration.md).
- Entrada CLI: python main.py <arquivo_json>
- Componentes principais: main.py, libs/Config, libs/UnifiedVideoEngine, libs/YouTube, libs/BackgroundVideo.
- Documentação completa de configuração: docs/configuracao-json-completa_Version2.md (origem): https://github.com/AbimaelPereira/AutomatedPythonVideoMaker/blob/5d843a3e46c60a4ea5a7ee83adbca386709b900c/docs/configuracao-json-completa_Version2.md
